# 2026-W48 — reports, questionnaires, legal review, and a beta ready to pack

Covers 23-28 November 2026.

## What was built
- **The author's own site, fixed with the tool's own findings** (23 November): the two problems found last week on `gcardinale.it` went online, a Content-Security-Policy without `'unsafe-inline'` for scripts and a `security.txt`. `scudo scan --web gcardinale.it` now gives 0 problems. The same day, the statistics subdomain added to the site went from 3 Medium findings to 0 after the tool was run on it.
- **Reports** (25 November, `scudo scan … --report <folder>`): every run can be written as HTML, PDF and JSON.
  - JSON with its own `schemaVersion` (1), fixed by a golden test.
  - HTML in a single file, every text encoded before it reaches the template.
  - PDF with MigraDoc and the DejaVu Sans font included: PDFsharp finds no system fonts on Linux and macOS, and with one included font the PDF is the same on every computer.
  - The attribution is on every page; a report stays in the language it was written in.
- **GDPR and NIS2 questionnaires** (25 November, `--profile`, `--company`, `--gdpr`, `--nis2`, `--answers`):
  - GDPR for a person: 5 good practices;
  - GDPR for a company: Articles 30, 13-14, 28, 32, 33-34, 35 and 37, with the technical findings of the same run used for Article 32;
  - NIS2 (Legislative Decree 138/2024): whether the organisation is in scope, then 5 obligations.
  - Questions in the terminal, or answers from a JSON file.
- **Legal review of the questionnaire texts** (27 November, PR #11). Sources read: the GDPR in Italian on EUR-Lex, the Garante's FAQ on the record of processing and its list of processing that needs a DPIA (decision 467 of 11 October 2018, read in full), Articles 3, 7 and 23-25 of Legislative Decree 138/2024 on Normattiva, and Annexes I and II on the PDF of the Gazzetta Ufficiale n. 230 of 1 October 2024. No obligation was wrong; 9 texts were made precise, for example:
  - the exemption of Article 30 below 250 employees also falls with data on criminal convictions (Article 10);
  - when data are not collected from the person, the notice is due within a reasonable time and at most one month (Article 14(3));
  - NIS2 food sector: industrial production, processing and wholesale only, not retail;
  - NIS2 Article 25: the final report is due one month after the notification.
  The questionnaires `gdpr-company` and `nis2` are now version `2026-11-27`. This is a preparatory check: a lawyer should confirm it before it is presented as legal advice.
- **PDFsharp 6.5** (28 November, PR #12): from 6.5 the library is AGPL-3.0-only (or commercial) and refuses to render until a license is chosen. Scudo Digitale is AGPL itself, so it now calls `PdfSharpLicense.SetAgplLicense()` before rendering.
- **The package of the beta** (28 November, PR #13):
  - version `0.1.0-beta`, written in every report (until now reports said 0.0.0);
  - `dotnet publish -r <rid>` gives one self-contained file, .NET included: about 40 MB for Windows;
  - a Release workflow that, on a tag, checks that the tag matches the version, runs the tests, builds and smoke-tests the executables for Windows, Linux, macOS Intel and macOS Apple Silicon, packs each with `LICENSE`, `NOTICE` and the font's license, writes `SHA256SUMS.txt` and creates a **draft** pre-release. Publishing is a manual step;
  - release notes that say how to verify the hash and how to open an executable that is not signed yet.

## What broke and how it was fixed
- **Article 32 said "in place" when nothing had been checked.** Found by an independent review on 25 November: if every technical check of the run was skipped or failed, the security question still came out fine. Now it counts only when at least one check actually ran, and it names the areas checked.
- **The printed HTML lost a line on every page.** The footer with the attribution covered the last line of each page when printing. It is now the footer row of a table, which browsers repeat on each page and leave room for. Checked by printing a 300-check report from Edge: no line lost.
- **The same review found 9 smaller things**, all fixed: a stricter JSON reader, questionnaire questions no longer counted as checks, a second report in the same second gets `-2` instead of overwriting, an error halfway leaves no partial files, any write error gives exit code 3, NIS2 thresholds summed over linked enterprises (Article 3(4)).
- **The specification was wrong on NIS2 thresholds.** It used turnover alone; Recommendation 2003/361/EC needs turnover **and** balance sheet total. The specification and the questionnaire were both corrected.
- **A doubt that the official source settled.** The HTML page of Annex I on Normattiva starts with "SCHEMA DI DECRETO" (draft decree) and has a typo in a sector name. Both are in the Gazzetta Ufficiale itself: the annex is right.
- **PDFsharp 6.5 stopped every PDF.** Seven existing PDF tests went red with `PdfSharpLicenseException: The loaded license is not valid`, which made them the counter-proof of the fix. The obvious "use the AGPL only if no other license is loaded" could not be written: `HasValidLicense()` is in the documentation but not public.
- **The first executable carried 10 extra files.** The `.pdb` and `.xml` of every library ended up next to `scudo.exe`; two publish settings remove them.
- **A test that could only pass by winning a race.** CI on PR #13 went red on macOS in a Core test I had not touched: "timed-out checks keep their slot". Its fake checks slept 300 ms against a 200 ms timeout, so they had to stay behind the timer by 100 ms; on a busy runner the timer fired late and one check finished first. The first run of the same code had been green, and I had only watched that one. The fake checks now wait for the timeout itself (the engine cancels their token) and then go on for 50 ms; counter-proof red when the slot is released at the timeout, 20 runs out of 20 green.
- **A test pinned the version to 0.0.0.** Raising the version turned it red. It now compares with the version of the build, and fails if that version is ever 0.0.0 again, that is, if it got lost on the way.

## Decisions taken
- [ADR-008 — Questionnaires in versioned JSON](../decisions/ADR-008-questionnaires-in-json.md): questionnaires are data, with English and Italian texts in the same file (a written exception to the `.resx` rule), answered in the terminal or from a file.
- PDFsharp moves to 6.5 under its AGPL license. A paid edition that does not publish its source would need PDFsharp's commercial license or another library: written in `docs/01-architecture.md`.
- The beta adds **macOS Apple Silicon** to the three x64 executables of the roadmap, since most Macs sold today are Apple Silicon. The macOS executables are built on macOS, because only there the SDK signs them, and Apple Silicon refuses an unsigned executable.
- Release drafts only: the workflow never publishes by itself.
