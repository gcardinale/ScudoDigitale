**First beta** of Scudo Digitale: a free, open-source, offline security self-assessment for the owner or the security officer of a domain. It checks the **email** and the **website** of a domain, asks the **GDPR** and **NIS2** questionnaires, and writes a report in **HTML, PDF and JSON**, sorted by severity, with the evidence and the fix of every problem. English or Italian, chosen from the language of the system.

> ⚠️ This is a beta: false positives and false negatives are possible. It is a self-assessment tool and does not replace a professional penetration test or legal advice.

## What it checks
- ✉️ **Email**: 11 passive checks on SPF, DMARC, DKIM and MX, read from public DNS only; no email is sent.
- 🔒 **Website**: 15 passive checks with the requests of a normal visit: HTTPS and redirect, certificate (expiry, chain, name), HSTS, Content-Security-Policy, clickjacking, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, cookies (Secure, HttpOnly, SameSite), security.txt.
- 📋 **GDPR** (good practices for a person, main obligations for a company) and **NIS2** (Legislative Decree 138/2024, Italy: scope and main obligations), texts checked against the official sources.
- 📄 **Report** in HTML, PDF and JSON, with the attribution on every page.

## Download
| System | File |
|---|---|
| Windows 10/11 (x64) | `scudo-0.1.0-beta-win-x64.zip` |
| Linux (x64) | `scudo-0.1.0-beta-linux-x64.tar.gz` |
| macOS, Apple Silicon (M1 and later) | `scudo-0.1.0-beta-osx-arm64.tar.gz` |
| macOS, Intel | `scudo-0.1.0-beta-osx-x64.tar.gz` |

Each archive holds a folder `scudo` with a single executable (`scudo`, .NET included), `LICENSE`, `NOTICE`, `THIRD-PARTY-NOTICES.txt` (the libraries inside the executable and their licenses), `DOTNET-THIRD-PARTY-NOTICES.txt` (those of the .NET runtime) and the license of the DejaVu font used in the PDF. Nothing to install on Windows and macOS; on Linux the ICU library must be present (`libicu`, already there on desktop distributions; on minimal systems and containers install it from the package manager).

**Verify the download** against `SHA256SUMS.txt`:
- Windows (PowerShell): `Get-FileHash .\scudo-0.1.0-beta-win-x64.zip -Algorithm SHA256`
- Linux: `sha256sum -c SHA256SUMS.txt --ignore-missing`
- macOS: `shasum -a 256 -c SHA256SUMS.txt --ignore-missing`

The executables are **not signed yet** (signing through the SignPath Foundation comes after v1.0):
- **Windows**: SmartScreen may show "Windows protected your PC" → *More info* → *Run anyway*.
- **macOS**: after extracting, run `xattr -dr com.apple.quarantine ./scudo` once in the folder where you extracted it, otherwise Gatekeeper blocks it.
- **Linux**: the file is already executable; if not, `chmod +x ./scudo/scudo`.

## Use
Open a terminal in the `scudo` folder (on Windows, the Command Prompt uses `.\scudo` instead of `./scudo`):
```bash
./scudo scan --mail example.com --web example.com --report ./reports
./scudo scan --profile Company --company "Example Ltd" --gdpr --nis2 --report ./reports
./scudo scan --help
```
DNS queries go to Cloudflare and then Google over DNS over HTTPS (they see only the domain names being checked); `--system-dns` uses the DNS of your computer instead. Nothing else leaves the computer: no telemetry.

## Not in this beta
TLS versions and ciphers, CMS detection, local network and CVE database (v0.2), Wi-Fi and Bluetooth (v0.3). See the [roadmap](https://github.com/gcardinale/ScudoDigitale/blob/main/docs/03-roadmap.md).

## Known limits
- The certificate revocation is not checked, so as not to contact servers that were not declared.
- In the PDF the severity is coloured text, not a coloured label.
